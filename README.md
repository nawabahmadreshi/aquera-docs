# Aquera Docs

Official documentation site for **Aquera** — Identity Governance & Administration platform.

Built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000

## Structure

- `_layouts/` — Page templates
- `_includes/` — Reusable HTML components
- `_data/` — Navigation data (YAML)
- `application/` — Integration guides
- `platform/` — Admin & platform docs
