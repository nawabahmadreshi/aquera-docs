# Aquera Docs

Official documentation repository for **Aquera** — Identity Governance & Administration platform.

## Overview

This repository contains the source files for the Aquera documentation portal, including:

- Getting Started guides
- Integration & API references
- Admin & User guides
- Release notes

## Structure

```
aquera-docs/
├── docs/           # Documentation source files
├── assets/         # Images, icons, stylesheets
└── README.md
```

## Contributing

All documentation is written in Markdown. To contribute:

1. Create a new branch from `main`
2. Make your changes
3. Open a Pull Request
